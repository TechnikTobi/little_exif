# Changelog

## `little_exif` v0.6.24

### Added
- **Changelog**: Added this `CHANGELOG.md` file

### Fixed
- **RUSTSEC vulnerabilities**: Two of the dependencies were affected
  by RUSTSECs, see [#100](https://github.com/TechnikTobi/little_exif/pull/100).

### Changed
- **MSRV Bump** As part of
  [#100](https://github.com/TechnikTobi/little_exif/pull/100), the MSRV needed
  to be bumped from 1.65 to 1.79. As I am not a big fan of this version bump
  myself, please let me know if this causes any problems for you so that
  we can look into other possibilities to perhaps lower that at some point
  in the future.
